mcp-sql

An AI assistant reads the index of your code over MCP. Keys are issued by a Telegram bot; after the chosen period the keys and your databases are deleted from the server.

Get keys in Telegram

How it works

  1. Keys. Open @mcp_sql_bot, press "Get keys" and choose a period: 5 hours, one day or one week.
  2. Index. Build the index of your project with the Indexer tool and upload it with your write key using the push command.
  3. Connect. Give your AI assistant the read key and the address https://your-server/mcp/DB_NAME. The assistant can only read.

Security and data

  • The write key is for you only, the read key is for the assistant. The server stores only their hashes.
  • Your databases are kept apart from other users' databases and cannot be reached with someone else's keys.
  • When the keys expire, the databases are deleted automatically, usually within a minute.
  • If the keys leak, press "Delete everything" in the bot: the keys are revoked and the databases are erased at once.
  • Do not upload anything you must not show to an assistant and to a server: the index contains source code and the project structure.
