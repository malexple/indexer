mcp-sql

ИИ-ассистент читает индекс вашего кода по MCP. Ключи выдаёт бот, а через заданный срок ключи и ваши базы удаляются с сервера.

Получить ключи в Telegram

Как это работает

  1. Ключи. Откройте @mcp_sql_bot, нажмите «Получить ключи» и выберите срок: 5 часов, сутки или неделя.
  2. Индекс. Постройте индекс проекта утилитой Indexer и загрузите его своим ключом записи командой push.
  3. Подключение. Дайте ИИ-ассистенту ключ чтения и адрес https://ваш-сервер/mcp/ИМЯ_БАЗЫ. Ассистент сможет только читать.

Занятость мест

Активные пары ключей: 5 часов — –, сутки — –, неделя — –. Свободно на диске: – ГБ.

Лимиты

Счётчики считаются по суткам UTC. Лимиты нужны, чтобы сервис хватало всем.

Безопасность и данные

  • Ключ записи только для вас, ключ чтения для ассистента. Сервер хранит лишь их хеши.
  • Ваши базы лежат отдельно от баз других пользователей и недоступны по чужим ключам.
  • Когда срок ключей истекает, базы удаляются автоматически, обычно в течение минуты.
  • Если ключи попали не в те руки, нажмите в боте «Удалить всё»: ключи отзываются, базы стираются сразу.
  • Не загружайте в индекс то, что нельзя показывать ассистенту и серверу: индекс содержит исходный код и структуру проекта.
